d# Parcial de Aprendizaje Automático

Repositorio correspondiente al trabajo práctico de Aprendizaje Automático.

## Estructura del repositorio

```text
Parcial-de-Aprendizaje-Automatico/
│
├── data/          Conjuntos de datasets utilizados
├── docs/          Descripción del Dataset CGMacros.
├── models/        Modelos de aprendizaje automático
├── notebooks/     Notebooks de Anaconda y Jupyter notebooks
├── references/    Material bibliográfico y de consulta
├── reports/       Informes y resultados
│
├── .gitignore     Configuración de archivos excluidos
└── README.md      Descripción y organización del repositorio
```

## Organización del trabajo

El repositorio utiliza una estructura basada en Cookiecutter Data Science para mantener separados los datos, los notebooks, los modelos y la documentación.
